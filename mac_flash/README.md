# Прямая прошивка MAC

Отдельное небольшое приложение для ручной записи MAC-адреса в U-Boot через SSH.
Оно не обращается к серийному номеру, плате, базе данных или Google Sheets и
не использует SPI. После записи приложение перезагружает устройство и проверяет
MAC штатной пост-проверкой из основного проекта.

Запуск из корня проекта:

```bash
python3 mac_flash/app.py
```

Нужны те же Python-зависимости проекта, в частности PySide6 и paramiko. Устройство
должно быть доступно для существующего в проекте механизма автоопределения сети;
учётные данные SSH сейчас совпадают с настройками основного приложения
(`root` / `infinityroot`).

Принимается MAC из 12 шестнадцатеричных символов: с двоеточиями, дефисами или без
разделителей. Например: `00:11:22:AA:BB:CC`.
